# 🌌 Cosmic Knowledge Graph

An interactive scientific knowledge graph exploring the Sun's orbit around the Milky Way and orbital mechanics around black holes.

## Overview

Cosmic Knowledge Graph is an interactive educational project designed to visualize the relationships between astronomy, gravity, orbital mechanics, black holes, and modern physics.

The project uses an interactive network graph to connect scientific concepts and explain how they relate to each other.

## Features

- Interactive knowledge graph
- 35+ scientific concepts
- 50+ concept relationships
- Five knowledge categories
- Search scientific concepts
- Filter concepts by category
- Click nodes to explore detailed explanations
- Related concept navigation
- Zoom, pan, and drag nodes
- Responsive interface
- GitHub Pages compatible

## Knowledge Categories

| Category | Description |
|---|---|
| Solar Galactic Orbit | The Sun's motion around the Milky Way |
| Black Hole | Black hole structure and orbital mechanics |
| Fundamental Physics | Gravity, angular momentum, and relativity |
| Scientific Evidence | Astronomical observations and experiments |
| Advanced Exploration | Scientific questions and thought experiments |

## Requirements

You only need:

- A modern web browser
- An internet connection
- GitHub account (optional for deployment)

The project uses:

- HTML5
- CSS3
- JavaScript
- vis-network

The vis-network library is loaded through CDN.

No Node.js installation or backend server is required.

## Run Locally

### Method 1: Open the HTML file

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application should open in your browser.

### Method 2: Use Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select "Open with Live Server".

## Deploy to GitHub Pages

1. Create a GitHub repository named `cosmic-knowledge-graph`.
2. Upload all project files while preserving the folder structure.
3. Open the repository's Settings.
4. Select Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select the `main` branch.
7. Select the `/ (root)` folder.
8. Click Save.

GitHub Pages will publish the website.

Your website URL will look like:

`https://YOUR-USERNAME.github.io/cosmic-knowledge-graph/`

Replace `YOUR-USERNAME` with your GitHub username.

## Scientific Notes

This project is an educational visualization, not a precision astrophysical simulation.

Some numerical values are approximate.

Important distinctions:

- The Sun orbits within the combined gravitational potential of the Milky Way.
- The Sun does not orbit Sagittarius A* as an isolated central mass.
- Objects can orbit black holes when their initial conditions permit stable orbits.
- An event horizon is not a solid surface.
- The Schwarzschild ISCO is located at 6GM/c².
- Kerr black hole orbital properties depend on spin and orbital direction.
